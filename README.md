# Password Manager 🔐

A simple Python-based Password Manager developed as part of my **Python Programming Internship**.  
The project provides a menu-driven interface for storing and viewing website credentials using a local JSON file.

---

## 📌 Project Overview

The Password Manager is a command-line application developed using Python. It allows users to store website credentials such as website name, username, and password in a structured JSON file.

The project demonstrates important Python programming concepts including:

- Functions
- Conditional Statements
- Loops
- Dictionaries
- File Handling
- JSON Data Management

---

## ✨ Features

### 1. Add Password
Users can enter:

- Website
- Username
- Password

The information is stored in `passwords.json`.

### 2. View Passwords
Displays all previously saved website credentials.

### 3. Exit
Closes the application.

### 4. Invalid Input Handling
The program displays an error message when an invalid menu option is entered.
